# BMI Calculator

A clean, simple, and responsive website to calculate Body Mass Index (BMI). Built using html css js, this tool allows users to input their height and weight to get their BMI.

## Features

* **Calculation:** Get your BMI immediately after submission.
* **Provides Health status:** Displays whether the result falls under underweight, normal weight, overweight, or obese.
* **Responsive Design:** Works on desktop, tablet, and mobile screens.
